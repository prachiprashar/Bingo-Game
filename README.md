# 🎯 Bingo Game

A simple and interactive **Bingo Game** built using **HTML, CSS, and JavaScript**. The game provides an engaging interface with both **Random Mode** and **Manual Mode**, allowing players to choose how they want to play.

## 🚀 Live Demo

🔗 **Play the Bingo Game:**
https://prachiprashar.github.io/Bingo-Game/

## 📂 GitHub Repository

🔗 **Source Code:**
https://github.com/prachiprashar/Bingo-Game

## ✨ Features

* 🎲 **Random Mode** – Automatically generates numbers for gameplay.
* ✍️ **Manual Mode** – Allows players to manually interact with the game.
* 🎯 Interactive Bingo gameplay.
* 🔢 Dynamic number generation and selection.
* 🖥️ Simple and user-friendly interface.
* 📱 Responsive design for different screen sizes.
* ⚡ Lightweight and fast-loading web application.
* 🚪 Exit option to leave the game.

## 🛠️ Technologies Used

* **HTML5** – Structure and layout of the application.
* **CSS3** – Styling, responsive design, and visual presentation.
* **JavaScript** – Game logic, interactions, and dynamic functionality.

## 🎮 How to Play

1. Open the **Live Demo**.
2. Select the desired game mode:

   * **Random Mode**
   * **Manual Mode**
3. Follow the on-screen instructions to play.
4. Continue selecting/generating numbers during the game.
5. Use the **Exit** option when you want to leave the game.

## 💻 Run Locally

To run the project on your local machine:

### 1. Clone the repository

```bash
git clone https://github.com/prachiprashar/Bingo-Game.git
```

### 2. Navigate to the project folder

```bash
cd Bingo-Game
```

### 3. Open the project

You can simply open:

```text
index.html
```

in your browser.

Alternatively, use **VS Code Live Server** to run the project locally.
